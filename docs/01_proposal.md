# 要望書（Proposal）

## 1. システム名称（仮）
ボートレース予想支援AIアプリ（開発コード：BoatAI）

## 2. システム概要
ボートレースにおける3連単予想の的中率向上を目的とした、AI予想支援Webアプリケーション。
ユーザー（自分＋少数の友達）が入力した出走表・直前情報・オッズ・記者予想・JLCデータ予想などの情報をもとに、AIが3段階（出走表確定時点／直前情報公開時点／締切直前）で予想（買い目）を更新・提案する。
単なる記録ツールではなく、ユーザー独自の分析ルール（例：当地2連対率トップ艇は頭候補から消さない、等）をシステムに蓄積・育成し、レースを重ねるごとに予想精度を高めていくことをコンセプトとする。

## 3. 開発背景・課題意識
- ボートレース予想は出走表・直前情報・オッズ・記者予想など多くの情報源を横断して分析する必要があり、経験則（ルール）が勝率向上の鍵になる。
- しかし、こうした分析ルールは頭の中や紙のメモに散在しがちで、体系的に蓄積・検証されにくい。
- 「当地2連対率トップ艇を無印・F持ちでも頭候補から消さない」といった具体的な教訓を、レースごとに記録・反映できる仕組みがあれば、AIの予想精度を継続的に育てられると考えた。

## 4. ターゲット層
- 開発者本人（ボートレース予想を継続的に行い、分析力向上を目指すユーザー）
- 開発者の少数の友人（同じ趣味を持ち、個々にアカウントを分けて利用する数名規模のユーザー）
- 不特定多数への公開は想定しない、クローズドな個人〜小規模グループ向けツール

## 5. 主な機能一覧
| No | 機能名 | 概要 |
|----|--------|------|
| 1 | レース記録・振り返り機能 | レースごとの出走表・直前情報・オッズ・買い目・結果を記録し、後から振り返れる |
| 2 | AI予想機能（3段階更新） | 出走表確定時点／直前情報公開時点／締切直前の3タイミングでAIが買い目を提案・更新 |
| 3 | ルール蓄積・管理機能 | ユーザー独自の分析ルール（教訓）を登録・編集し、AI予想に反映する |
| 4 | 収支管理機能 | 1,000円予算（200円×5点）ベースで収支を記録し、AI提案通りに買った場合の収支もシミュレーション |
| 5 | AI対話・深掘り機能 | AIの予想根拠についてチャット形式で深掘りできる |
| 6 | ユーザー認証機能 | メール＋パスワードによるアカウント管理（友人ごとに分離） |
| 7 | モバイル対応（PWA） | スマートフォンのブラウザからも快適に利用可能、ホーム画面追加に対応 |

## 6. 想定される効果
- 分析ルールが資産として蓄積され、レースを重ねるほどAI予想の精度が向上する仕組みを構築できる。
- 一般戦（地方競走）で数多くのレースを通じてルールを検証・強化し、SG等の大舞台では検証済みルールを活用するという、レース規模に応じた育成戦略が取れる。
- AI提案通りに買った場合の収支を可視化することで、自分の判断とAIの判断のどちらが優れていたかを定量的に比較できる。

## 7. 開発環境・技術方針（概要）
- フロントエンド：React（PWA対応、レスポンシブデザイン）
- バックエンド：Python（FastAPI）
- データベース：Supabase（PostgreSQL、無料枠）
- AI連携：Claude API
- デプロイ：Vercel（フロント）／Render（バックエンド）／Supabase（DB）、いずれも無料枠を活用

## 8. 今回のスコープアウト（やらないこと）
- 出走表・直前情報等の自動スクレイピング取得（今回は手動入力。将来拡張として設計のみ考慮）
- 不特定多数への公開・SNS的な共有機能（フォロー、タイムライン等）
- 課金・決済機能（実際の賭け金決済は行わず、あくまで予想シミュレーション）
